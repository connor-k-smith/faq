# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's **Security** tab to
submit a private vulnerability report:

https://github.com/connor-k-smith/faq/security/advisories/new

Include the affected component, reproduction steps, potential impact, and any suggested mitigation.
Do not include real credentials, respondent links, or production data. You can expect an initial
response within seven days.

Only the latest revision of the `main` branch receives security fixes.
